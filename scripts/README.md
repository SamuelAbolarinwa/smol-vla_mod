# Scripts Directory

This directory contains utility, data preparation, local check, and remote execution scripts.

## Intended Layout
- `local/`: Local verification, linting, packaging checks, and repository maintenance utilities.
- `kaggle/`: Kaggle notebook drivers, GPU execution launchers, and dataset mounting helpers.
- `deploy/`: Jetson Orin Nano export, ONNX/TensorRT optimization, and latency/memory benchmarking runners.
- `eval/`: Offline metric calculation and closed-loop environment evaluation scripts.
